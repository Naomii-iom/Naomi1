# Why Are We Here?

## Initial Question

If AI can increasingly write working code from natural language, why should I, as a designer, still learn programming?

## My Initial Position

I think learning programming is still important, but not mainly because I need to write code myself.

I need to understand the basic principles behind programming so that I can judge whether AI-generated solutions are reasonable, communicate my design intentions more precisely, and transfer what I learn to new problems.

## A Personal Example

I once worked on an interactive screen project in a subway passage. I used AI to generate the interaction I wanted.

However, the code did not work. I did not understand the code well enough to identify the problem, so I repeatedly told the AI that it did not work and asked it to modify the code.

Eventually, I asked someone else for help. They found that the problem was actually a very small numerical error.

This made me realise that being able to ask AI to generate code is not the same as understanding code.

## Questions I Want to Explore

- What does it mean to actually understand programming?
- If AI writes the code, what does the designer still need to know?
- How does understanding programming help me describe an idea as a clear specification?
- How can programming knowledge transfer to different design problems?
